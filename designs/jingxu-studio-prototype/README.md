# 镜序 Studio 高保真交互原型

## 设计上下文

- 产品：镜序 Studio，本地优先的 AI 漫剧创作工作台。
- 原型范围：创作输入、剧本开发、分镜设计、画面生成、视频生成、合成导出六阶段。
- 设计来源：正式 Renderer 的 `AppShell.tsx`、`WorkspaceLayout.tsx`、`workspace-status.ts`、`styles.css`。
- 流程参考：用户确认的 Glowave X 连续创作流程；不复制其品牌、素材或无限画布。
- 设计系统：仓库没有已编译的 `_ds_manifest.json`，本原型从现有应用提取色彩、状态、间距和组件语义，自由重组为评审原型。

## 关键设计决策

1. 全局导航与项目流程分离：全局导航负责产品区域，项目流程栏负责当前作品与六阶段。
2. 分镜、图片、视频阶段复用同一镜头上下文，避免用户反复寻找当前镜头。
3. 每个页面只突出一个主要操作；不可用操作仍显示原因。
4. 版本、锁、任务和错误证据放入检查器，通过标签页渐进展示。
5. 原始领域枚举不作为主文案；界面统一使用中文状态。
6. 原型提供紧凑/舒展密度切换，用于评估桌面窗口的信息密度。

## 本地打开

- 可直接双击 `index.html`，也可通过本地 HTTP 服务打开。
- `prototype.js` 是预编译运行文件，避免浏览器通过 Babel 跨文件读取本地 JSX 时触发 `file://` 安全限制。
- `entry.jsx` 是 `data.jsx`、`components.jsx` 与 `app.jsx` 的预编译入口。

## 评审重点

- 新用户能否识别当前位置和下一步。
- 分镜到视频的镜头上下文是否连续。
- 检查器是否保留专业能力但不干扰主流程。
- 合成前阻塞项与导出反馈是否清楚。
