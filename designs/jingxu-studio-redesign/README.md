# 镜序 Studio · UI 重设计（去 AI 味）

## 评审背景

旧原型（`../jingxu-studio-prototype/`）的信息架构经过验证，但视觉是典型的「AI 生成面板脸」。本次重设计保留骨架，重做皮肤。

## 旧版 AI 味诊断 → 新版对策

| 症状 | 旧版做法 | 新做法 |
|---|---|---|
| 靛蓝紫强调色（AI 面板标配） | `#6078ea` 蓝紫渐变 | 每方向单一信号色，全界面只有一处主色 |
| 全局蓝调 | 海军蓝底 `#080d19` | 中性碳灰 / 暖墨底，无色偏 |
| 默认系统字 | 微软雅黑 | Noto Sans SC + IBM Plex（可打包本地化） |
| 药丸徽章 + 彩点满天飞 | `.status` 圆角胶囊 | 文字 + 6px 方形标记，无框无底色 |
| 大写间距眉标 | `EYEBROW` 全大写 | 去大写；细小灰字「阶段 01 / 06」 |
| 渐变光晕假预览 | radial-gradient 场景 | 平涂色块 + 1px 构图线，诚实标注为示意 |
| 圆角卡片 + 阴影堆叠 | radius 10 + 大阴影 | 1px 分割线分区；阴影只给浮层 |
| 层级靠颜色 | 彩色文字区分 | 字号 / 字重 / 灰度层级为主，颜色只表达状态 |
| 数字用正文字体 | 「45 秒」混排 | 等宽字体时间码（CINE）/ 表格数字（INK） |

## 两个方向（顶栏切换器）

### CINE 剪辑台（主方向）

后期机房的工具理性：近黑碳灰底、单一信号橙（tally 灯逻辑：橙 = 激活/主操作）、1px 精密分割线、IBM Plex Mono 时间码、4px 圆角、无渐变无光晕。

### INK 墨韵（对照方向）

深夜书房的文学气质：暖墨底、朱砂点睛、宋体标题与章回式汉字序号（一至六）、国画暗调缩略色、6px 圆角。

两方向共享：布局骨架（全局导航 208px / 流程轨 264px / 检查器 360px / 顶栏 48px）、全部七屏内容与交互、同一份数据。

## 范围

创作输入、剧本开发、分镜设计、画面生成、视频生成、合成导出（含配音与字幕）、模型服务设置；其余全局区域保留诚实占位。

## 本地打开

必须经 HTTP 服务打开（多文件 Babel 原型，`file://` 会静默失败）：

```bash
cd AI项目/designs
python -m http.server 4311
# http://localhost:4311/jingxu-studio-redesign/index.html
```

字体经 CDN（loli 镜像）加载，离线时回退 PingFang / 雅黑；正式落地时应打包本地字体。

## 评审重点

1. 切换两个方向，感受「工具理性 vs 文学气质」哪个更像镜序该有的样子。
2. 六阶段流程与镜头上下文连续性是否被新视觉强化而非削弱。
3. 检查器的专业信息（版本、锁、任务证据）在去卡片化后是否仍然清晰。
4. 时间码、状态文字、按钮层级是否消除了「AI 面板感」。

## 落地状态（2026-09-10）

CINE 已落地正式 Renderer（openspec change `cine-workspace-theme`）：两份 CSS 全量角色映射、`:root` 补上从未定义过的 `--jx-*` 令牌（修复边框/指示点静默丢失）、117 个字体切片本地打包。布局尺寸与 E2E 断言保持不变。实况截图见 `screens/real-app-*.png`。原型中的状态系统（失败/过期/空态横幅、字段锁定、任务进度）与 INK 方向尚未落地，留待后续 change。
