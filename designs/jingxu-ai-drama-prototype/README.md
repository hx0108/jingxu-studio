# 镜序 AI漫剧 / 短剧创作平台高保真原型

## 设计定位

- 产品统一定位为“AI漫剧 / 短剧创作平台”。
- 整体采用单任务、单画布的六步中文向导。
- 分镜、画面与视频共用横向镜头故事板和选中镜头大预览。
- 素材随镜头管理；生成任务进入“更多”；导出记录进入合成导出页。
- 除产品定位中的 `AI` 外，用户界面不展示英文状态、字段或按钮。

## 10 个页面

1. 开始创作
2. 我的作品
3. 故事构思
4. 剧本完善
5. 分镜设计
6. 画面生成
7. 视频生成
8. 合成导出
9. 质量评测
10. 设置

## 可点击范围

- 漫剧 / 短剧选择、新建与继续创作。
- 六步创作流程跳转。
- 场景、镜头、候选和评测对象选择。
- 生成、重新生成、暂存、继续、合成与导出反馈。
- 版本与锁定、生成任务和加载/空白/失败状态演示。
- 未保存离开确认、服务管理弹窗和全局提示。
- 合成导出页提供可操作时间轴：三轨片段选择、播放定位、拖动改位、双端裁剪、分割、复制、删除、撤销与重做。
- 对白轨和配乐轨支持静音、音量调节；配乐片段支持淡入和淡出，刷新页面后保留当前剪辑状态。

## 本地预览

从仓库根目录运行：

```powershell
python -m http.server 4311 --directory designs
```

然后访问：

`http://localhost:4311/jingxu-ai-drama-prototype/index.html`

该原型使用纯 HTML、CSS 与 JavaScript，不依赖联网加载。

## 组件化高保真版本

- `reference-originals/` 保存用户提供的 10 张原始页面 PNG，仅作为视觉验收基准，不直接充当产品页面。
- `assets/media/` 保存本地优化后的全屏电影感背景、项目封面、人物画面、镜头缩略图、候选图和参考图。
- 十页全部由真实 HTML、CSS 与 JavaScript 组件组成，不使用整页截图或透明点击热区。
- 页面宽度随浏览器响应式变化；背景始终覆盖完整视口，不再出现固定画布产生的左右黑边。
- 首页、作品、故事、剧本、分镜、评测与设置页锁定为单个浏览器视口高度；内容较长的画面生成、视频生成和合成导出页采用隐藏滚动条的工作区滚动，确保候选、时间轴、导出设置与历史记录均可完整查看。
- 可交互范围包含作品类型与筛选、搜索、故事表单、可编辑剧本、六阶段导航、镜头与候选、播放与时间轴、生成状态、导出设置、评测折叠项、服务管理、未保存确认以及加载／空白／失败状态。

## 剪辑能力边界

合成导出页是“真实可操作的高保真原型”：用户可以在浏览器内完成时间轴编辑并看到状态、时长、预览画面和检查结果联动，适合验证交互流程和开发验收。当前版本不读取真实媒体文件，也不执行视频解码、音频混音或成片编码；“生成成片”仍是原型反馈，正式产品需要接入媒体引擎后才能导出真实视频。
