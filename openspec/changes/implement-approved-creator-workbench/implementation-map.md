## 共用正式组件

- 品牌头与精简导航：`AppShell`
- 六步流程、页面标题、固定操作栏：工作台壳组件
- 镜头条、候选卡、大预览、属性检查器：媒体工作区组件
- 加载、空白、失败、成功、只读故障和 dirty 离开确认：统一页面状态组件
- “更多”抽屉：收纳素材、任务、导出证据、版本与锁定，不删除既有能力

## 数据边界

- `designs/jingxu-ai-drama-prototype/data.js`、`app.js` 和浏览器 `localStorage` 仅是原型演示数据，不进入正式 Runtime。
- 正式查询通过 `window.jingxu` 的逐方法 IPC，正式写入由 Main/Application 校验并在 SQLite 事务中提交。
- Renderer 可以保留未保存的界面草稿和最多 30 步撤销/重做，但刷新后只从当前持久化版本恢复。
- 本地背景和场景图是只读打包资源；项目生成媒体仍通过受限媒体 URL 读取，不把绝对路径暴露给 Renderer。
