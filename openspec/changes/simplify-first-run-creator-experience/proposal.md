## Why

镜序 Studio 已具备从故事输入到媒体导出的多阶段能力，但普通用户首次进入时仍需要理解 Provider、JSON、版本、锁和任务等工程概念，且必须自行判断下一步，导致“能力完整”没有转化为“第一次就能完成”。本变更以 PRD v1.4 §2.3 的核心创作任务、§5 的完成效率指标和 §15.1 的页面状态规则为依据，把现有链路收敛为一个可在约 5 分钟内理解并完成的引导式首次体验，同时保留高级用户所需的证据与可追溯性。

## What Changes

- 新增“5 分钟体验模式”：使用内置示例故事、合成参考资产、默认 9:16 参数和现有确定性 Mock 适配器创建独立演示项目，不要求凭据或网络；界面必须明确标识“演示结果/不会产生真实费用”，不得把 Mock 结果表示为真实 Provider 质量或能力证据。
- 首页收敛为唯一主要操作“继续制作本集”。系统以持久化项目状态确定当前最早阻断步骤，并直接定位到可执行页面；无项目时进入体验模式/创建作品入口，不要求用户先理解六阶段配置。
- 新增“生成前准备向导”，一次聚合生成服务就绪情况、角色参考图、画风参考图、预计时长、参考成本和阻断项，并为每个阻断项提供直接修复入口。准备结果只读聚合既有凭据、预检、分镜和参考价格事实，不由 Renderer 或模型猜测。
- 将五个剧本阶段的默认 JSON 文本区替换为按正式 `ScriptStageOutput` 字段组织的结构化表单；分镜继续使用结构化镜头编辑。原始 JSON 仅在用户主动展开“高级编辑”后出现，并继续通过现有 Schema、并发版本和事务边界保存。
- 普通创作路径默认不展示 JSON、Provider、内部版本状态、能力快照、锁、任务 ID、哈希和内部枚举；用户首先看到中文任务、影响和下一步。诊断、历史恢复和高级编辑仍可按需进入，不删除底层证据。
- P1 的整集质量驾驶舱、证据前后对比、返工影响计算、局部返工批次、跨项目模板和轻量版本分支视图不纳入本 Change；它们将在 P0 首次成功路径通过目标用户试用后分别立项。

## Capabilities

### New Capabilities

- `first-run-creator-experience`: 约束 5 分钟体验模式、首页确定性续作解析和生成前准备向导的用户行为、边界与验收。

### Modified Capabilities

- `guided-creator-workspace`: 将默认工作区从工程状态面板调整为普通用户任务界面，规定唯一续作入口、技术信息渐进披露和生成前向导入口。
- `staged-script-generation`: 将五阶段默认编辑方式从 JSON 全文编辑改为正式 Schema 对应的结构化表单，并保留高级 JSON 与既有不可变版本语义。
- `storyboard-media-workspace`: 在真实媒体生成前集中展示参考资产、时长、参考成本和阻断项，并禁止默认界面暴露 Provider/能力快照等内部概念。

## Impact

- **Renderer**：影响首页、项目工作区导航、`ScriptWorkspace`、`WorkspaceLayout`、分镜/媒体主操作和设置入口；新增首次体验、结构化阶段表单及准备向导组件。
- **IPC / Application**：新增只读“下一步/准备状态”查询与演示项目初始化命令；必须由 Application 层确定性聚合现有项目、阶段、凭据、资产预检、媒体状态和参考价格，Renderer 不自行推导业务状态。
- **Adapters / data**：复用现有 Mock 文本、图片、视频、配音和本地合成链路；示例故事与参考资产作为随应用发布的合成 Fixture。预计不修改四份 PRD-owned JSON Schema；若实现核实后需要新增持久化字段，必须以追加 migration 和独立审查处理。
- **安全与兼容性**：真实生成继续遵守 TECH_DESIGN v1.1 §6 的凭据、固定 Provider 和零静默回退规则；体验模式与真实项目必须视觉和数据隔离。既有版本、锁、审计和导入导出契约保持兼容，只改变默认展示与入口。
- **测试与发布**：覆盖 Application 单元测试、IPC Contract、Renderer 状态测试和 Playwright Electron 首次体验/真实准备向导 E2E；涉及关键 Renderer 流程，按 TECH_DESIGN v1.1 §3.5 运行完整门禁与相关 E2E。当前 `v1-acceptance-evidence` 的用户试用构建需在本变更 Apply 后重做，避免用旧交互版本证明首次成功率。
- **并行工作风险**：当前工作树存在 Agnes 图片 Provider 相关未提交修改。本 Change 的 Apply 阶段不得覆盖这些修改；准备向导只消费稳定的服务就绪查询，若必须触及同一 Provider Contract 或设置组件，应先重新核对并拆分冲突。
