# V1 目标用户试用执行单

真实用户试用不能由自动化测试代替。每位用户独立完成一次，建议总时长不超过 90 分钟。

## 给用户的 5 分钟说明

1. 创建项目，输入原创创意，或导入 UTF-8 `.txt/.md` 剧本。
2. 依次运行文本阶段，确认一版结构化分镜。
3. 修改一个未锁字段，再锁定一个字段尝试修改，观察系统是否阻断。
4. 做一次分镜排序或复制，导出结构化分镜 JSON。
5. 只记录实际遇到的问题，不替用户修正输入。

## 组织者准备

```powershell
$env:JINGXU_E2E_EVIDENCE_DIR = "<试用证据目录>"
pnpm test:e2e
```

目标用户至少 3 人，分别记录开始/结束时间、是否代操作、错误码、修改次数、是否成功导出、主观评价和 Bad Case。使用 [`trial-record-template.md`](./trial-record-template.md)；不得把开发者自测结果填入用户记录。
