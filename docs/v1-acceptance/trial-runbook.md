# V1 目标用户试用执行单

真实用户试用不能由自动化测试代替。每位用户独立完成一次，建议总时长不超过 90 分钟。

## 首次体验试用（3 名目标用户）

三人各自使用一份全新本地数据目录，不得由组织者预先配置任何 API Key。记录“开始点击体验”到“首次看到准备向导”的有效操作时间，同时记录墙钟时间。

1. **完全新手**：从首页点击“继续制作本集”后选择“5 分钟体验”，浏览示例故事、分镜与参考图，再点击“为整集生成首帧”。成功标准：能说出准备向导中的服务、参考图、时长与成本含义；不得把“零真实费用”误解为真实成片已完成。
2. **有创作经验但未用过镜序**：创建自己的作品，填完故事概念并保存；在默认表单中完成，不主动提示高级编辑。成功标准：不需要阅读 JSON、版本号、锁、Profile 或 Provider 才能找到下一步。
3. **从示例转真实创作的用户**：先运行体验，再创建自己的作品并打开一次“生成服务”。成功标准：能区分演示结果与真实制作；真实项目未继承示例的 Mock 成功事实或凭据。

每次都记录首次完成率、有效操作时间、墙钟时间、求助点、误解点和 Bad Case。任何人未完成时，也记录其所在页面和未能理解的中文文案；不得由组织者代操作后计为成功。

## 原有 V1 工作流试用

1. 创建项目，输入原创创意，或导入 UTF-8 `.txt/.md` 剧本。
2. 依次运行文本阶段，确认一版结构化分镜。
3. 修改一个未锁字段，再锁定一个字段尝试修改，观察系统是否阻断。
4. 做一次分镜排序或复制，导出结构化分镜 JSON。
5. 只记录实际遇到的问题，不替用户修正输入。

## 最新十页工作台与 V2 三轨试用

该部分单独记录，不与 V1 AC 或首次体验结果合并。

1. 从“我的作品”进入真实项目，依次完成故事构思、剧本完善和分镜设计；记录每一步是否能在不解释内部枚举、Profile 或版本号的情况下找到唯一主要操作。
2. 在“画面生成”和“视频生成”滚动到最后一个候选，确认滚轮、PageDown 和 Tab 均可到达；新任务界面只显示 Agnes 白名单模型，不得出现 Seedance/万相新建入口。
3. 在“合成导出”分别选择画面、对白和配乐片段，执行移动、双端裁剪、分割、复制、删除、撤销/重做、静音、音量和淡入淡出；未保存时尝试导出，确认系统要求保存、放弃或取消。
4. 保存后重启应用，确认只恢复 SQLite 当前时间线版本；再执行一次本地 FFmpeg 导出并记录真实文件结果。不得把工作预览描述为最终成片。
5. 单独记录四类证据：Mock 主链、真实本地 FFmpeg、真实 Agnes 探针、目标用户观察。探针未获得显式授权或凭据时写“未运行”，不得写成通过；历史探针结果不得替代本轮证据。

每位用户还需记录所用窗口大小和缩放比例、发生滚动的页面、无法发现的高级入口、错误码、保存/恢复结果及是否误把演示数据当成真实生成结果。
