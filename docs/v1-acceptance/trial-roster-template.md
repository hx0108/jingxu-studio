## 发布门槛核对

- [ ] 三名用户各自独立完成统一任务。
- [ ] 每人用时不超过 90 分钟。
- [ ] 至少两人评价“少量修改后可继续进入图片/视频生产”或更高。
- [ ] 没有锁字段静默变化。
- [ ] 每人的记录、导出 hash、错误和 Bad Case 已归档。
