## 单人会话流程

1. 组织者记录构建哈希、用户编号和开始时间。
2. 仅使用 [`../trial-runbook.md`](../trial-runbook.md) 进行不超过 5 分钟的说明。
3. 用户独立完成“创意或已有剧本 → 可导出结构化分镜”，最长 90 分钟。
4. 组织者只记录操作、错误和求助；不代操，不替用户修改输入。
5. 导出后记录文件 SHA-256、结束时间和用户评价，将 Bad Case 拆分记录到 [`../bad-case-template.md`](../bad-case-template.md)。
6. 每人结束后将证据保存到独立目录，不在普通日志中复制完整剧本或 API Key。
